# IntervuAI

IntervuAI is a full-stack MERN application designed to help users prepare for job interviews through personalized AI-powered mock interview sessions. Users can upload their resumes, and the platform generates customized technical and HR interview questions based on their skills, experience, and target roles.

The platform provides secure Google authentication, credit-based access control, Razorpay payment integration for premium usage, interview history tracking, and intelligent AI-generated feedback to help users continuously improve their interview performance.

## Key Features

* Resume-based personalized interview question generation
* Technical and HR mock interview sessions
* AI-powered performance feedback and evaluation
* Secure authentication using Firebase Authentication
* Credit-based SaaS payment system with Razorpay
* Interview history and progress tracking
* Responsive and user-friendly interface

## Tech Stack

* Frontend: React
* Backend: Node.js + Express
* Database: MongoDB
* Authentication: Firebase Authentication
* Payments: Razorpay
